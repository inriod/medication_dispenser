# Medication Dispenser CAD Design

## Overview

This project presents a CAD-based automated medication dispenser concept designed to support organized and timely pill delivery. The device is focused on improving medication management for users who may need reminders, dose organization, and easier access to the correct medication.

The design includes a rotating dispensing mechanism, medicine storage compartments, a hinged lid, a safety lock, and a basic user interface concept.

## Main Features

- Rotating medicine compartment system
- Gear-driven dispensing mechanism
- Hinged lid design
- Safety lock for controlled access
- User interface concept
- Exploded assembly view
- BOM and material planning

## Design Description

The medication dispenser is designed as a compact automated device for storing and dispensing medicine in an organized way. The rotating compartment system is intended to separate doses, while the gear-driven mechanism supports controlled movement of the dispenser.

The hinged lid and safety lock improve usability and help prevent unwanted access to multiple doses. The user interface concept supports interaction with the device and improves accessibility for the end user.

## Materials Concept

The design uses lightweight plastic materials for the main body, lid, covers, and battery case. Rubber is used for the legs, metal is used for the stepper motor gear, and polypropylene is considered for the rotating wheel.

## Project Goal

The goal of this project is to create a practical CAD concept for an automated medication dispenser that improves dose organization, user accessibility, and treatment adherence.
